## Projects

### VulnWatch

A vulnerability monitoring side project that collects and normalizes vulnerability data from **cve.now** and the **CISA Known Exploited Vulnerabilities (KEV) catalog**.

- Built with FastAPI, SQLAlchemy, Alembic, and PostgreSQL.
- Uses source adapters and idempotent data updates.
- Enriches selected vulnerabilities with affected products, fix versions, CVSS details, and references.
- Preserves the last successful data and checkpoint when a source fetch fails.

### Wazuh Security Operations Lab

A hands-on security monitoring lab integrating **Suricata, Wazuh, Shuffle, TheHive, and Cortex**.

- Sends Suricata alerts to Wazuh for detection and rule matching.
- Tests detections for network scans and web login activity in a lab environment.
- Uses Shuffle workflows to triage alerts and create TheHive alerts for investigation.
